# Matanot: הפתעות בקישור

דף נחיתה ו-7 אתרי דוגמה. HTML, CSS ו-JavaScript נקיים, בלי framework ובלי שלב build.

## מבנה הקבצים
| קובץ | מה יש בו |
|---|---|
| `config.js` | **כל הטקסטים, המחירים, הקישורים והטלפון של דף הנחיתה.** זה הקובץ לעריכה |
| `styles.css` | העיצוב. הצבעים מוגדרים בראש הקובץ (`:root`) |
| `index.html` | מבנה דף הנחיתה |
| `main.js` | בונה את הדף מתוך ההגדרות: הדגמה חיה, סינון דוגמאות, אנימציית הפרופיל |
| `a11y.js` | תפריט הנגישות |
| `negishut.html` | הצהרת נגישות |
| `privacy.html` | מדיניות פרטיות |
| `images/` | תמונות מוקטנות לאתר (הלוגו, התמונה שלך, אייקון) |
| `demos/engine.js` + `engine.css` | **מנוע ההפתעות**, משותף לכל הדוגמאות |
| `demos/*.html` | 7 אתרי דוגמה. כל אחד הוא רק רשימת שלבים |

## איך בונים הפתעה ללקוח
מעתיקים את אחד הקבצים ב-`demos/` ומשנים את `window.DEMO`: הצבעים ב-`theme` ואת השלבים ב-`steps`.

סוגי השלבים שהמנוע מכיר:
`envelope` (מעטפה) · `message` (הודעה) · `choice` (בחירה) · `runaway` (כפתור לא שבורח) · `checklist` (רשימה לסימון) · `quiz` (טריוויה) · `scratch` (כרטיס גירוד) · `photos` (אלבום פולרואיד) · `hold` (לב שמתמלא) · `candles` (נרות לכיבוי) · `notes` (קיר פתקים) · `countdown` (ספירה לאחור) · `final` (סיום: `ticket` / `invite` / `card`)

תשובה של הלקוח בשלב `choice` עם `key` אפשר להציג בהמשך כ-`{key}`. דוגמה ב-`date.html`.
